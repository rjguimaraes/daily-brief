# Daily Brief

Sistema pessoal de inteligência e aprendizado. Repositório privado.

- `memory/` — memória editorial (JSONL) e critérios de curadoria, lidos antes de cada edição.
- `scripts/` — coletores e utilitários Python (camada de dados, sem modelo de linguagem).
- `.github/workflows/` — execuções agendadas e manuais no GitHub Actions.
- `reports/` — saídas dos testes e relatórios de qualidade.

Regra central: nenhum número do painel é digitado à mão ou gerado por modelo; todos vêm de séries coletadas, com fonte e data.
